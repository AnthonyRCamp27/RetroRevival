# 🎮 Retro Revival

**Retro Revival** is a full-stack web project inspired by the golden era of arcade and console gaming.  
It combines a nostalgic pixel-art design with modern web technologies to create an interactive experience for users to browse, search, and learn about classic video games.

---

## 🕹️ Overview

Retro Revival reimagines vintage web aesthetics with a functional, database-driven backend.  
The site showcases a catalog of classic games using dynamic content rendered from a MySQL database through PHP scripts.  
Users can search for titles, explore details, and enjoy a nostalgic, neon-inspired design built with pure HTML & CSS.

---

## 🚀 Features

- 🎨 **Retro-Themed UI** – Neon color palette, pixel fonts, and arcade-style transitions.
- 📚 **Dynamic Game Catalog** – Lists classic games pulled directly from a MySQL database.
- 🔍 **Search & Filter** – JavaScript-driven search by title, genre, or release year.
- 🧩 **CRUD Functionality** – Admin panel allows adding, editing, and deleting games.
- ⚡ **Responsive Layout** – Optimized for desktop, tablet, and mobile.
- 🖥️ **Server-Side Integration** – PHP scripts handle data retrieval and submission securely.
- 🧠 **Structured Database Design** – MySQL schema built for scalability and clean queries.
